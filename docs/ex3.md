## 小テスト {: .exercise }

小テストは 4 講時の講義パートのあとに行います。問題は前回の aiJudge 課題の内容に沿っています。受験できるのは **1-608 の教室だけ**で、オンラインでは受験できません。

- **16:30〜16:45** の 15 分間で、aiJudge の次の課題に取り組んでください。
- 解答は aiJudge の Web エディタで書いて提出します。ファイルを選んで提出する形式ではありません。コースの画面で、問題セットの見出しの下にある「エディタで解く」を押してください。
- 受験中はデスクトップ画面の静止画を撮影します。エディタを開くと「画面全体を共有して始める」が表示されるので、これを押し、共有する画面として「画面全体」を選んでください。タブやウィンドウだけを共有した場合は受験できません。
    - 共有している間、画面全体の静止画が数秒おきに撮影されます。動画・音声・カメラは撮影しません。撮影した画像を見られるのは担当教員だけです
    - **画面の共有を止めると提出できません**。止めてしまったら、画面上部の「画面の共有を再開する」を押してください
    - 通知やほかのアプリも撮影されるので、小テストの前に関係のないアプリや通知を閉じておいてください
    - 小テスト中に使えるディスプレイは、**自分のノート PC の画面だけ**です。演習室のディスプレイ、持ち込んだタブレットやスマートフォンは使えません
    - 小テストに使う PC 上で、仮想デスクトップによる複数画面の切り替えは使えます。Windows では「仮想デスクトップ」（タスク ビューから使います）、Mac では Mission Control で使う複数の「スペース」（デスクトップ）です
    - 詳しくは [aiJudge 学生向けガイド（エディタで解く問題セット）](https://sanoakr.github.io/aijudge/student/) を参照してください
