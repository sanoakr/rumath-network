# ex8 — まとめの小テスト（1-608 対面）

最終回は、講義パート、通常の小テスト、演習課題のいずれも行いません。4 講時（15:30〜16:30）に「まとめの小テスト」を対面で行います。終了後の 5 講時は、任意提出のレポート課題などについての質問に佐野が対応します。

## まとめの小テスト（1-608 対面） {: .exercise }

- 日時: **11月13日（金）4 講時 15:30〜16:30**（60 分）
- 場所: **1-608**（対面で実施）
- 方法: 座席指定。**1-608 の実習室 PC** で、問題の提示と提出を aiJudge の Web エディタで行います
- 内容: これまでの小テストに準ずる内容
- 参照可: 自分のソースファイル、ネットワーク検索、書籍やノートなどの持ち込み資料
- 参照不可: 他者や AI とのコミュニケーション（チャット・ファイル送付・ChatGPT など）
- 配点: 科目評価の 35%

!!! danger "1-608 の実習室 PC の Web エディタからしか提出できません"
    - 受験と提出は **1-608 の実習室 PC だけ**で行います。自分のノート PC や、学外からは提出できません
    - 実習室 PC のブラウザで aiJudge を開き、コースの画面で test8 の見出しの下にある「エディタで解く」を押してください。解答はエディタで書いて提出します（ファイルを選んで提出する形式ではありません）
    - エディタを開くと「画面全体を共有して始める」が表示されます。これを押し、共有する画面として「画面全体」を選んでください。**画面の共有を止めると提出できません**
    - 使えるディスプレイは、**実習室 PC に設置されたディスプレイだけ**です。自分のノート PC、タブレット、スマートフォンの画面は使えません
    - 手順は、第 7 回（11/06）の演習課題 ex7（まとめの小テストのリハーサル）で一度試しておいてください

!!! tip "自分のプログラムは、事前に実習室 PC にコピーしておく"
    自分のソースファイルは参照できますが、受験中に使えるのは実習室 PC だけです。これまでに書いたプログラム（ex3〜ex7 の `.py` ファイルなど）は、**小テストの前までに**、OneDrive などのクラウドストレージや USB メモリで実習室 PC にコピーし、開けることを確かめておいてください。
